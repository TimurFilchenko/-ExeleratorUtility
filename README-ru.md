# Exelerator Utility

Exelerator Utility — консольная программа для Windows x64, написанная на языке C.

Программа предназначена для поиска одинаковых файлов и безопасного удаления ненужных копий.

## Как работает

Exelerator:

1. Сканирует выбранную папку и её подпапки.
2. Находит файлы.
3. Сравнивает их размеры.
4. Вычисляет SHA-256 для подходящих файлов.
5. Группирует одинаковые файлы.
6. Показывает найденные группы.
7. Позволяет выбрать файлы для удаления.
8. Запрашивает подтверждение перед удалением.

## Запуск

Установка не требуется.

Запустите:

```text
Exelerator.exe

Программу можно запустить через Windows Terminal, Command Prompt или напрямую через File Explorer.

Сборка

Проект использует C, Make и LLVM-MinGW.

Для сборки выполните:

make

Готовый файл появится здесь:

build/Exelerator.exe

Для очистки файлов сборки:

make clean

Безопасность

Exelerator не должен автоматически удалять найденные дубликаты.

Перед удалением пользователь выбирает файлы и подтверждает операцию.

Из каждой группы дубликатов должна оставаться хотя бы одна копия.
